## Медиа

Полный пофайловый реестр: [assets/media-manifest.json](assets/media-manifest.json). Он содержит оригинальный URL CDN, публикацию/страницу обнаружения, размеры и исходную подпись. Оптимизация: WebP, 640px responsive варианты и до 1400×1600 для больших кадров, без увеличения исходников, без AI-ретуши, исходные пропорции сохранены. Обрезка в CSS отдельно проверяется визуально. VR — реальная обложка видео компании, не сгенерированная картинка. Фото команды для выпускного относится к публикации выпускного сезона.

Логотип из публичной публикации компании сохранён без перерисовки. Упрощённая буква «К» используется только как техническая favicon демонстрации. Шрифт Manrope — Google Fonts, локальный WOFF2; OFL в assets/fonts/OFL.txt.
