# QA / SEO / Redteam

Дата: 07.09.2026. Объект: единственная коммерческая посадочная страница Kinder Party Dom. Реальный Chrome, Playwright Test CLI 1.63.0, локальный HTTP-сервер. Встроенный Browser runtime не предоставил доступного браузера; использован установленный Chrome через Playwright.

## До публикации — пройдено

`npm.cmd run build`, `npm.cmd test` — 3 из 3 сценариев прошли. `npm.cmd run qa` — все восемь размеров прошли: 360, 375, 390, 430, 768, 1366, 1440, 1920px (высота 900px). Дополнительно интерактивный мобильный тест 390×844.

Для каждой ширины: HTTP 200; 0 ошибок страницы/консоли; 0 ответов ресурсов >=400; 0 битых изображений; 0 несуществующих якорей; 0 горизонтальных переполнений; ровно один H1. Основные CTA и элементы взаимодействия не меньше 44px. Дополнительный машинный поиск элементов меньше 24px не выявил нарушений.

Функциональные сценарии:
- мобильное меню, aria-expanded, закрытие после выбора раздела;
- переход к площадке;
- открытие фото, загрузка, стрелки в обе стороны, Escape, возврат фокуса;
- фокус внутри dialog при Tab;
- раскрытие/закрытие FAQ;
- более 20 WhatsApp CTA: номер и непустое корректное сообщение, возраст «10+» не превращается в пробел;
- мобильный звонок tel:+79825357237;
- 7 программ и 4 реальных отзыва в статическом HTML при отключённом JS;
- FAQ работает без JS;
- JSON-LD соответствует видимому FAQ, подтверждённый адрес, без aggregateRating;
- prefers-reduced-motion отключает smooth scroll;
- CSS, JS, favicon SVG/PNG, touch icon, OG, robots и sitemap доступны.

Машинные результаты: qa/local-report.json. Скриншоты полного desktop/mobile и hero всех размеров хранятся локально в `.research/qa`, не публикуются как сайт.

## Визуальная проверка / DESIGN.md

Проверены desktop hero 1440, мобильные hero 375/390, программы, VR, площадка, герои, дополнения, фотоальбом, отзывы, городская секция, FAQ и финальные контакты. Сохранены натуральные фото, молочный фон, один ягодный цвет действий, единые мягкие радиусы, отсутствие тяжёлых теней и градиентов. Акцент в фотографиях не перекрашен.

Исправления по результату:
1. Подпись к татуировке-лапке не называет её сквишем; добавлена видимая подпись изображения.
2. Для «Сможешь Пати» выбран реальный архивный кадр подростков; это атмосферный кадр фотоальбома, не утверждение о съёмке именно этой программы.
3. В галерее пространства вместо слишком узкого панорамного кадра — два отдельных фото, всего 5 кадров площадки.
4. Устранена пустая ячейка в мобильном фотоальбоме.
5. Увеличены мобильные подписи длительности и программных действий, добавлен отступ под подписью фото выездного блока.
6. Исправлен alt выездного блока: фото артистов в помещении не описывается как съёмка на улице.

## SEO — проверено в коде и браузере

Охват: главная, служебная 404, все локальные ресурсы HTML, JSON-LD, sitemap. Одна страница с логичной иерархией заголовков, содержательными разделами и якорями; полезный текст присутствует в HTML без рендеринга JS. Уникальные title/description, абсолютный canonical/OG URL, локальный OG 1200×630, favicon, lang=ru, alt и размеры фото. Sitemap содержит только главную. 404 содержит noindex.

EntertainmentBusiness включает подтверждённые адрес/часы/телефон; FAQPage совпадает с visible FAQ и сохранён по заданию. Он не заявлен как способ получить rich result: [Google прекратил показ FAQ rich results в мае 2026](https://developers.google.com/search/updates), проверено 07.09.2026. [Robots.txt — отдельный механизм управления обходом](https://developers.google.com/search/docs/crawling-indexing/robots/intro); robots проекта в подпапке GitHub Pages не управляет корнем хоста. Это ограничение явно описано в README.

Фактические позиции, индексация, Search Console и полевые Core Web Vitals не измерялись; рост трафика и расширенные результаты не обещаются. Изображения локальные WebP с responsive вариантами, ниже hero lazy loading, шрифт локальный; production artifact около 6.8 MB целиком, не объём первой загрузки.

## Ограничения внешних проверок

VK прочитан в живом браузере. Прямая страница 2ГИС потребовала CAPTCHA; использован поисковый индекс, обход не проводился. Поэтому числовой рейтинг/счётчик отзывов не заявлены. Телефон и WhatsApp проверены как ссылки и по публикациям компании; реальный звонок/отправка сообщения не выполнялись. Точные ссылки Telegram/MAX отсутствуют и не придуманы.
