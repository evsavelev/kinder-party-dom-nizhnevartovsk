# Kinder Party Dom — направление и reference lock

Дата: 07.09.2026. Отдельный коммерческий демонстрационный сайт для родителей Нижневартовска. Главная задача — выбрать формат и перейти к обсуждению даты в WhatsApp. Реальная компания, реальные фото, без выдуманных обещаний.

## Исследование до реализации

Refero Free: каталог доступен, поиск и полные design systems получены для Playful, Adanola и Dash Digital Studio.

Три рассмотренных направления:
1. Playful (https://playful.software): тёплая бумага, один акцент, мягкие формы, крупный наклонный шрифт. Приятная эмоциональность; иллюстрационный SaaS hero и градиенты здесь не подходят.
2. Adanola (https://adanola.com): фотографический lookbook, фото в движении, простая навигация по категориям, ровная сетка, минимум оформления вокруг карточек. **Основное направление: семейный фотожурнал.**
3. Dash Digital Studio (https://dashdigital.studio): крупная типографика и двухколоночная галерея. Слишком строгий монохром и тонкий display для детского праздника; не переносим систему.

Отраслевые сайты изучены по открытым страницам:
- https://www.puddles.london/ — выбор видов праздника и отдельное предложение выездных артистов.
- https://www.tokenstudio.co.uk/kids-party — понятное объяснение творческого формата, спокойное обращение к родителям.
- https://www.londonmuseum.org.uk/visit/families/birthday-parties/ — видимая длительность, ограничения и состав предложения.
- https://www.siobhandavies.com/use-our-studio/space-hire/childrens-parties/ — площадка как самостоятельная ценность, фотографии пространства.
- https://www.houseofgpa.com/birthday-parties — сценарии и конкретный следующий шаг.

## Выбранная система

Основная композиция Adanola: фотоматериал занимает большую долю экрана, натуральные цвета, повторяемые карточки, крупные пары фото, небольшие подписи. Не копируем fashion branding. Осознанные изменения по брифу: молочная подложка, ягодный цвет действий, мягкий радиус 20px, заметные кнопки 48–56px для родителей на телефоне. От Playful переносим только принцип одного акцента для действий; его иллюстрации, шрифт italic, тени и градиенты не используем.

### Токены
- Canvas #faf7f2; поверхность #ffffff; текст #292422; вторичный текст #68605d; разделитель #ded7d0.
- Primary/action #a72b50; hover #87213f; светлый акцент #f3e1e6. Тёплый жёлтый #f2d782 — только небольшая информационная метка, не второй CTA.
- Шрифт: локальный Manrope variable с кириллицей, системный Arial fallback. Заголовки 650–750, текст 400–500; без искусственного italic. H1 62–76px desktop / 37–44px mobile; H2 40–48 / 30–34; body 16–18px, line-height 1.6.
- Сетка: max-width 1320px, поля 40px desktop / 20px mobile, 3 колонки программ desktop, 2 tablet, 1 mobile. Секции 96px / 56px, gap 24px / 16px.
- Кнопки pill 48–56px; primary ягодный с белым текстом; secondary обводка; тексты действий конкретные. Focus-visible 3px с отступом, hover только цвет/небольшой сдвиг стрелки.
- Карточки без теней, фото 4:3 или 4:5, описание и цена под фото; поверхности используются для объединения информации.
- Фото без цветовых фильтров, лица сохраняются. Hero — реальный кадр праздника; подписанные фото для площадки и персонажей. Никаких сгенерированных гостей, стоковых праздников или вымышленных изображений услуг.

### Композиция и адаптивность
- Лаконичная навигация, split hero с большим фото и двумя CTA. На телефоне компактный текст и кадр, ключевой CTA до фото.
- Форматы → программы → состав часа → площадка/выезд → подбор по возрасту → герои/дополнения → фотогалерея → отзывы → городской опыт → порядок/FAQ → контакты.
- Мобильная нижняя панель: дата в WhatsApp и звонок, safe-area и запас внизу документа. Не перекрывать lightbox.
- Галерея: ванильный dialog, Escape, стрелки, возврат фокуса, подписи и полноразмерное изображение без обрезки.
- Никаких autoplay, параллакса, каруселей, конфетти. prefers-reduced-motion отключает плавную прокрутку и переходы.

## Решения и ограничения

Цена у каждой программы имеет статус ориентира по открытым публикациям. Контактная дата — запрос менеджеру, не обещание свободного слота. Возрастные кнопки формируют сообщение для консультации, не приписывают неподтверждённые возрастные рамки программам. Адрес, часы и 40 гостей подтверждены пользователем в этой сессии. Показать реальные короткие выдержки отзывов со ссылкой, без придуманных аватаров/рейтинга schema.

## QA против reference lock

Проверить фото на всех контрольных ширинах, единые цвета/кнопки/радиусы, отсутствие тяжелых теней, плотной радуги и декоративных пустых блоков. Путь от hero к запросу даты должен занимать один переход.
